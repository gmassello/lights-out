# Notes API — tiny factory test case

## Goal

Build a minimal HTTP service that stores notes. The product is deliberately minimal: this case
exists to run every seat of the factory end to end as fast as possible, not to challenge the
implementation.

## Spec

### Runtime contract

- Listen on `0.0.0.0`, port from the `PORT` environment variable (default `8080`). No other
  configuration; no network access at runtime.
- `GET /health` returns `200` with `{"status":"ok"}` within 30 seconds of container start.
- `POST /_test/reset` deletes all notes and returns `204` with no body within 10 seconds.
- Every error response has status 4xx and the body
  `{"error":{"code":"<code>","message":"<human readable>"}}`.
- Any unknown route or method returns `404` with code `not_found`.
- Storage may be in memory.

### Note

```json
{"id": "<opaque string>", "title": "<string>"}
```

- `title`: required, string, 1 to 100 characters.
- `id`: generated by the server, unique.

### Endpoints

| Method and path | Success | Errors |
|---|---|---|
| `POST /notes` | `201` with the created note | `400 bad_request` (body is not a JSON object), `422 validation_error` (missing or invalid `title`) |
| `GET /notes/{id}` | `200` with the note | `404 not_found` |
